# 사이트 설계도(PRD) — 새싹 공방

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.
※ 새싹 공방은 리더플 AI 스쿨 실습실의 **교육 실습용 가상 예시**다.

## 1. 한 줄 정의
주말에 2시간이면 완성하는 도자기·캔들 원데이 클래스 공방

## 2. 손님
- 누가: 손으로 뭔가 만들어 보고 싶은 20~40대 직장인, 커플, 회사 동호회 총무
- 어디서 알고 오나: 인스타그램 작품 사진, 지인 소개, "원데이 클래스" 검색

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 처음인데 할 수 있나
2. 몇 시간 걸리고 얼마인가
3. 언제 가능한가, 몇 명까지 되나

## 4. 믿게 할 증거 (실제로 있는 것만)
- 수업 사진, 수강생이 만든 작품 사진 (사진 준비 중)
- 한 반 최대 6명 소수 정원
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 수업 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 버튼 + 이번 주말 수업 시간
2. 수업 두 가지 — 시간·가격·만드는 것
3. 처음이어도 괜찮나요 — 자주 묻는 질문 3개
4. 후기 자리 (비워 둠)
5. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 희망하는 수업과 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 도자기 머그 만들기 45,000원 / 소이 캔들 만들기 35,000원 (재료비 포함)
- 시간: 도자기 2시간 / 캔들 1시간 30분 · 토·일 오후 2시, 4시 30분
- 정원: 한 반 최대 6명
- 위치: 수업 확정 시 개별 안내 (가상 예시라 주소 없음)
- 연락 방법: 사이트 문의 폼

## 9. 이번에 넣지 않을 것
- 온라인 결제, 회원가입, 블로그

## 10. 첫 화면 한 문장 후보
1. 주말 2시간, 도자기·캔들 원데이 클래스
2. 처음이어도 2시간이면 내 머그가 생겨요
3. 손으로 만드는 주말, 새싹 공방

## 11. 다음에 할 것
- 실제 수업·작품 사진 넣기
- 첫 후기 받으면 후기 자리에 넣기
- 단체(동호회) 문의용 안내 한 줄
